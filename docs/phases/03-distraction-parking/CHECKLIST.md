# Phase 03 Completion Checklist

## Capture flow

- [ ] Focus 页面有低视觉权重的 `记录一个念头` 入口。
- [ ] 点击后可立即输入。
- [ ] 非空文本可暂存并立刻返回 focus。
- [ ] 空文本不会产生记录。
- [ ] 快速重复提交不会产生意外重复记录。
- [ ] 写入失败不会悄悄丢失未提交文字。
- [ ] distraction 与正确 session 关联。
- [ ] 重启 App 后记录仍存在。

## Attention design

- [ ] Capture 不暂停或重置计时。
- [ ] Focus 页面不展示 distraction 内容列表。
- [ ] 没有标签、分类、优先级、Todo、提醒。
- [ ] 没有奖励、分数、连续签到或 AI 分析。

## Lifecycle

- [ ] Capture 打开时切后台/回来行为稳定。
- [ ] 已结束 session 不能新增 distraction。
- [ ] Android 键盘交互通过。
- [ ] iOS 键盘交互通过。
- [ ] Phase 02 全核心回归场景通过。

## Gate

- [ ] typecheck/lint 无阻塞问题。
- [ ] MANIFEST exit gate 全部满足。
